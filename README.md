# 合同运价报价台（可追溯报价闭环）

- 行业：合同物流
- 技术栈：Vue3、Vite、TypeScript（localStorage 本地留痕）
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 业务规则

1. **运价版本匹配**：报价按 `客户等级 + 运输线路 + 计费重段 + 服务类型 + 有效期` 匹配运价台账中的生效版本；多版本命中取最晚生效的版本（合同换版）。
2. **无适用版本阻止发送**：组合不存在、重量超出重段、不在有效期内、唯一版本已撤销等情况均阻止发送，并提示具体原因；不会产生报价记录。
3. **发送即冻结**：发送成功时冻结快照——运价版本号、单价、起步价、燃油附加费率、基础运费、燃油附加费、总额、币种、报价有效期、冻结时间，并生成 FNV-1a 快照指纹。
4. **修订不覆盖**：已发送报价不可编辑、不可删除，只能「新建带原因的修订」；修订重新匹配现行版本、冻结新快照并追加到修订链，原报价各版本快照永久保留。
5. **撤销留痕**：运价版本撤销必须填写原因；撤销后不再参与新报价/修订匹配，但历史报价仍按冻结快照核对金额。
6. **刷新一致**：运价台账、报价链、修订记录全部持久化到 localStorage；刷新后对每个快照执行核对，区分「一致 / 版本已撤销 / 运价已调整 / 快照被篡改」四种结论，链与版本状态保持一致。
7. **草稿**：草稿不冻结金额、可删除；点击发送时才进行版本匹配与快照冻结，匹配失败同样被阻止。

## 演示数据（种子）

- 客户：海沃商贸(VIP)、云仓食品(合约)、南陵机械(标准)
- 运价：上海-南京/杭州-合肥/广州-深圳三条线路的多版本、多重段运价；其中广州-深圳冷链合约版本已带原因撤销。
- 报价：
  - `Q-SEED-0001`：跨合同年度的报价，首发快照冻结 2025 旧版单价，后以「重量调整+2026 版生效」为由修订一次；
  - `Q-SEED-0002`：引用的冷链版本事后被撤销，演示「历史报价仍按快照核对」；
  - `D-SEED-0003`：草稿，可直接发送。

## 建议核对路径

1. 打开 `Q-SEED-0002` 的「核对快照」→ 结论为「版本已撤销」，金额仍与快照一致；
2. 在台账中撤销 `RV-SHNJ-VIP-STD-B2-2026`，再对 `Q-SEED-0001` 新建修订 → 无生效版本被阻止，历史快照核对不受影响；
3. 刷新页面后再次核对 → 链、修订记录与版本状态完全保持。
