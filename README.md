# 合同运价报价台

- 行业：物流（合同运价 / 报价）
- 技术栈：Vue3、Vite、TypeScript、Pinia
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 业务闭环

1. **运价版本化**：运价按「客户等级 + 线路 + 服务类型 + 计费重区间 + 生效日期」建档；
   同维度重叠区间建档新版本时，旧版本有效期自动截断并记录 `supersedesId` 顶替关系；
   版本可撤销（必须填原因），撤销后新报价不可再匹配，已被报价引用的版本不允许删除。
2. **报价匹配与阻止**：发送报价时按客户等级、线路、计费重、服务类型与今日日期匹配唯一生效版本；
   无适用版本（未建档 / 已撤销 / 未到生效日 / 超重量区间）时发送被阻止并提示原因；可先存草稿。
3. **发送即冻结**：报价发送瞬间把单价、燃油附加费率、最低收费、基础运费、燃油附加费、
   总额（CNY）及报价有效期起止写入快照（`QuoteSnapshot`）。
4. **修订链不可覆盖**：已发送报价不可编辑或删除，只能「新建修订」且必须填写原因；
   修订按当日运价重新匹配并冻结新快照，原报价置为「已修订」、保持只读，同链编号 `BJ-0001 → BJ-0001-R2`。
5. **撤销后仍可核对**：历史报价始终以快照核对。引用版本被撤销后，报价显示
   「版本已撤销，按快照核对」；版本仍在则重算金额，金额一致显示「与现行运价一致」，
   不一致显示漂移提示但报价金额不变。
6. **刷新一致**：数据持久化在浏览器 localStorage，刷新后报价链、版本状态、核对结果保持一致；
   右上角「重置演示数据」可恢复种子数据。

## 代码结构

- `src/types.ts`：运价版本、客户、报价、快照等领域模型
- `src/pricing.ts`：运价匹配、计价、快照构建与核对纯函数
- `src/seed.ts`：演示数据（含已撤销版本、未来版本、首版+修订链）
- `src/store.ts`：Pinia store，运价建档/撤销/换版、报价发送/草稿/修订/关闭
- `src/components/`：报价表单、报价链卡片、快照展示、运价版本管理
